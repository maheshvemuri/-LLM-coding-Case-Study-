# LLM-coding-Case-Study
Estonia IMF Report Analysis
This notebook analyses Estonia’s 2025 Article IV Consultation report, IMF Country Report No. 25/181.
How to Run
1. Open 23079988.ipynb in Google Colab.
2. Select a GPU runtime for the local Qwen model.
3. Upload the IMF PDF as REPUBLIC OF ESTONIA.pdf.
4. Run all cells in order. Internet access is required to download models and dependencies.
Outputs
Summaries, economic indicators, dashboards, RAG answers and audit files are saved under /content/estonia_imf/.
Limitations
Some citations and evaluator outputs require review. Summary evaluation predates the revised summaries, and some assignment-required extractions remain unimplemented. Automated checks do not establish factual accuracy.
